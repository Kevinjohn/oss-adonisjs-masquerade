The Lucid entry point is optional. Install and configure Lucid only when using the included Lucid
store; another `ControlStore` can be supplied through the core contract. The `testing` entry point
is for tests and adapter conformance, not application persistence.

## Generated signatures and imports

Generated pages may show internal or framework types in a public signature so TypeScript contracts
are readable. That does not make their source modules importable. Import package types from
`adonisjs-masquerade/types` or another listed entry point, and do not deep-import `src/`,
`integration/`, or other implementation paths. The package's [declared export map](https://github.com/Kevinjohn/oss-adonisjs-masquerade/blob/main/package.json) is the authority for supported paths.
